# Hand Woven | Handcrafted Crochet, Flowers & Baby Clothes

A luxury, clean, and minimal landing page for a premium handcrafted brand **Hand Woven**, specializing in hand-crocheted everlasting flowers, bouquets, and newborn baby clothing.

## Features

- **Luxury Theme**: Warm neutral colors (cream, sand, gold) with elegant typography.
- **Scroll Reveal Animations**: Fluid animations that highlight the craftsmanship step-by-step.
- **Client Testimonials Slider**: Smooth carousel presenting reviews from design lovers and families.
- **Interactive Lightbox Modal**: Custom image preview lightbox for both product grids and the Instagram showcase.
- **Micro-interactions**: Gold link underlines, button ripple rises, preloader sequence, scroll bar timeline, and pulse waves.
- **Fully Responsive**: Adapts fluidly (mobile-first grid shifts, overlays, opaque menus) from 320px to 4K displays.
- **Direct Instagram Orders**: There is no checkout cart; instead, visitors order products through Instagram DMs.
